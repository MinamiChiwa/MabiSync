# MabiSync · 瑪奇 Mobile 多人同步工具

作者：**南千和** · [爱发电](https://afdian.com/a/minamichiwa) · [Patreon](https://patreon.com/chiwaminami)

和朋友一起触发表情动作，或让多个合奏小组按同一个倒计时开始演奏。支持公网建房、成员分组与排序、乐器分工，以及房主统一停止演奏。本工具由AI辅助制作。

**[下载 Windows x64 发布包](https://github.com/MinamiChiwa/MabiSync/releases/latest)** · [完整使用说明](docs/guide.zh-CN.txt)

## 安装

适用于 Windows 10/11 x64。下载 Windows x64 压缩包，完整解压到可写文件夹，双击 `MabiSync.exe`。已包含 .NET、Node.js 和 Cloudflare 组件，无需另行安装运行时。

```text
MabiSync.exe
App/          程序及运行组件
Config/       乐器列表.txt，可自行添加乐器
Docs/         使用说明与第三方许可
```

昵称、乐谱及加入顺序识别需要另装 **[Npcap（官方下载）](https://npcap.com/#download)**，包内未附带驱动。装好后重新打开“抓包校对”。普通表情同步和手动开停可在未安装 Npcap 时使用。

升级时先退出旧程序，将新包解压到新目录；设置保存在 `%LocalAppData%\MabiSync`。如果修改过乐器文件，请保留旧目录的 `Config/乐器列表.txt`。

## 和朋友连接

1. 首次启动时填写自己的游戏昵称，也可通过抓包识别更新。默认选择“服务器直连（非长期）”，房主创建房间后点击“复制邀请”发给朋友。
2. 成员粘贴完整邀请或输入六位房间码，点击“加入房间”。异地电脑也可加入。
3. 房主选择“表情动作”或“合奏”，勾选参与者并设置 1–60 秒倒计时。
4. 成员完成本机设置后点击“就绪”。房主直接点击“开始”，无需另点就绪。

联机方式：

- **服务器直连（非长期）**：默认选项，通过加密连接使用临时提供的房间服务器。成员可以用完整邀请或六位房间码加入；服务到期或维护期间可改用其他方式。
- **Cloudflare 公网**：由房主电脑运行房间服务，通过临时隧道分享邀请。
- **局域网**：同一网络或已用组网软件连通的电脑使用。选中后显示地址框和“连接教程”，按教程建房或加入。

复制成功后，按钮旁会显示“邀请已复制”。剪贴板临时占用时会自动重试；仍无法写入时，下方会显示完整邀请，可选中后按 Ctrl+C。

连接中断后，点击房间区域的“重新连接”。确认原身份和最新成员列表后会显示恢复成功，成员再重新就绪。房主断线后仍可关闭房间；重连等待中也可直接关闭或离开。无法取得服务端关房确认时，会明确提示本机退出结果。

## 表情动作

推荐使用“预填指令 · 仅按回车”：玩家先在游戏聊天框填好自己已拥有的动作指令，成员就绪后切回游戏，房主点击“开始”。倒计时结束时工具按一次回车。每轮自行重新填好指令。

也可直接录入快捷键，或使用“点选按钮位置”记录游戏按钮。表情流程只触发一次；开始前可取消。

## 合奏

- 房主在成员列表设置各人的组号、组内顺序、乐谱使用者身份和乐器，可直接输入数字、选择下拉项或拖动昵称。修改会同步给全员。
- 各组乐谱使用者在背包选好自己的乐谱，点选乐谱使用按钮，停止默认使用空格键，也可自定义。组员只需确认停止设置，按列表顺序在游戏中手动加入。
- 停止方式在底部状态卡设置，初次使用默认“总指挥一轮后全员停止”，也可选择手动统一停止或指定时长。已有设置会保留。总指挥的乐谱用于确定全队一轮终点，各组仍由各自乐谱使用者开始。
- 一轮停止需要总指挥启用抓包识别。进入“抓包校对”选择游戏与通道，点击“开始”后切换地图或重新登录角色，等到昵称被识别。乐谱信息和停止倒计时显示在底部。
- 成员列表用颜色提示加入顺序：绿色正确、红色不符、黄色待加入、灰蓝色待核对。本机昵称加粗显示。

## 操作与调整

每次启动默认开启“操作游戏”；关闭可先做模拟。选择正确的游戏窗口并完成绑定，执行时保持游戏在前台。房主点击开始会恢复并激活所选游戏窗口。

“本机动作”集中显示游戏窗口、输入方式和开始/停止绑定，进房前也可设置。窗口列表显示标题、进程与最小化状态；最小化后仍可选择，勾选“显示其他窗口”可手动选择其他目标。房主开始后，各参与者会在确认准备前自动恢复、激活自己选中的窗口；若系统拒绝激活，会在准备阶段显示具体原因。取消与停止在恢复窗口期间仍可使用。

各张卡片可点击标题收起，保留设置摘要。时间微调默认展开，收起后仍显示数值和提前/延后方向。

底部状态卡折叠后仍可开始、就绪或停止。房主可看到全员是否就绪；成员的就绪按钮未准备时为红色，已准备时为绿色。顶部身份栏显示自己的组别、身份、顺位与乐器。

右上角图钉切换窗口置顶，划线眼睛切换录屏隐藏，两项每次启动默认开启，高亮表示开启，灰色表示关闭。录屏隐藏需要 Windows 10 2004 或更高版本及兼容的采集软件，部分采集方式仍可能显示窗口。

抓包按所选游戏进程与网络连接运行，最小化不会清除已有观测；重新打开校对窗口会显示运行中的游戏和网卡。选择其他服务器窗口可用于普通输入同步，自动身份和乐谱解析仍以已适配的客户端为准。

快捷键框支持直接按键录入。“点选按钮位置”会暂时隐藏工具，点击目标位置后恢复；右键、Esc 或本机停止快捷键（默认 F9）取消。窗口尺寸或 Windows 缩放改变后需要重新点选。

**F9：本机取消 / 停止。** F9 被占用时自动尝试 `Ctrl+Alt+F9`、`Ctrl+Shift+F9`，实际按键显示在“本机动作”中；全部被占用时，仍可正常就绪和开始，需要停止时使用窗口按钮。合奏中会尝试停止本机演奏，房主另有“全员停止”。

“本机时间微调”范围为 −2000～+2000 毫秒，**负数提前、正数延后**；滑块支持 1 毫秒调整，也可直接输入整数。修改后重新就绪。

工具在就绪和开始前自动校时；倒计时过短时会为提前量和网络准备补足时间，并显示本轮实际倒计时。界面使用暗色主题，下拉菜单支持点击或键盘选择，鼠标滚轮只滚动列表与页面。

## 使用前了解

本工具不是游戏官方软件。抓包和自动键鼠操作可能违反游戏规则或触发检测，存在账号处罚风险，请自行评估。工具使用普通前台输入和被动网络观测，不读取游戏进程内存、不注入、不发送或重放游戏数据包；这些方式不构成账号安全保证。

当前抓包适配面向港澳台服，韩服、日服尚未验证。一轮停止使用抓包估计起点和乐谱周期，实际游戏停止效果仍需按自己的环境确认；数据不足时请用房主手动全停。输入回执仅代表系统已发送输入，不代表角色已成功执行。同步效果可用本机时间微调调整。

默认诊断不保存原始抓包、完整乐谱或聊天草稿。房间内会共享昵称、分组、角色关联、乐谱摘要和操作状态，请只向可信玩家分享邀请。

赞助完全自愿，不影响工具功能。
