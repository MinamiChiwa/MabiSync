# MabiSync · 瑪奇 Mobile 多人同步工具

作者：**南千和** · [爱发电](https://afdian.com/a/minamichiwa) · [Patreon](https://patreon.com/chiwaminami)

和朋友一起触发表情动作，或让多个合奏小组按同一个倒计时开始演奏。支持公网建房、成员分组与排序、乐器分工，以及房主统一停止演奏。

**[下载 Windows x64 发布包](https://github.com/MinamiChiwa/MabiSync/releases/latest)** · [完整使用说明](docs/guide.zh-CN.txt)

## 安装

适用于 Windows 10/11 x64。下载 `MabiSync-0.1.0-win-x64.zip`，完整解压到可写文件夹，双击 `MabiSync.exe`。已包含 .NET、Node.js 和公网组件，无需另行安装运行时。

```text
MabiSync.exe
App/          程序及运行组件
Config/       乐器列表.txt，可自行添加乐器
Docs/         使用说明与第三方许可
```

昵称、乐谱及加入顺序识别需要另装 **[Npcap（官方下载）](https://npcap.com/#download)**，包内未附带驱动。装好后重新打开“抓包校对”。普通表情同步和手动开停可在未安装 Npcap 时使用。

升级时先退出旧程序，将新包解压到新目录；设置保存在 `%LocalAppData%\MabiSync`。如果修改过乐器文件，请保留旧目录的 `Config/乐器列表.txt`。

## 和朋友连接

1. 房主填写昵称，点击“创建公网房间”。底部显示公网已就绪后，点击“复制邀请”发给朋友。
2. 成员粘贴完整邀请，点击“加入邀请”。异地电脑也可加入。
3. 房主选择“表情动作”或“合奏”，勾选参与者并设置 1–60 秒倒计时。
4. 成员完成本机设置后点击“本机就绪”。房主直接点击“开始”，无需另点就绪。

公网连接使用 Cloudflare 临时隧道，可达性取决于各自网络。连接失败时查看底部提示，可重试或在“高级连接”使用局域网、自有服务地址。关房后成员退出，旧邀请失效。

## 表情动作

推荐使用“预填指令 · 仅按回车”：玩家先在游戏聊天框填好自己已拥有的动作指令，成员就绪后切回游戏，房主点击“开始”。倒计时结束时工具按一次回车。每轮自行重新填好指令。

也可直接录入快捷键，或使用“点选按钮位置”记录游戏按钮。表情流程只触发一次；开始前可取消。

## 合奏

- 房主在成员列表设置各人的组号、组内顺序、发起者身份和乐器，可直接输入数字、选择下拉项或拖动昵称。修改会同步给全员。
- 各组发起者在背包选好自己的乐谱，分别记录开始按钮和画面上的停止按钮。组员只记录停止按钮，按列表顺序在游戏中手动加入。
- 房主可选手动统一停止、指定时长，或“总指挥一轮后全员停止”。总指挥的乐谱用于确定全队一轮终点，各组仍由各自发起者开始。
- 一轮停止需要总指挥启用抓包识别。进入“抓包校对”选择游戏与通道，点击“开始”后切换地图或重新登录角色，等到昵称被识别。乐谱信息和停止倒计时显示在底部。
- 成员列表用颜色提示加入顺序：绿色正确、红色不符、黄色待加入、灰蓝色待核对。本机昵称加粗显示。

## 操作与调整

每次启动默认开启“操作游戏”；关闭可先做模拟。选择正确的游戏窗口并完成绑定，执行时保持游戏在前台。房主点击开始会恢复并激活所选游戏窗口。

快捷键框支持直接按键录入。“点选按钮位置”会暂时隐藏工具，点击目标位置后恢复；右键、Esc 或 F9 取消。窗口尺寸或 DPI 改变后需要重新点选。

**F9：本机取消 / 停止。** 合奏中会尝试本机停止演奏，房主另有“全员停止”。“本机时间微调”范围为 −2000～+2000 毫秒，**负数提前、正数延后**；修改后重新就绪。

## 使用前了解

本工具不是游戏官方软件。抓包和自动键鼠操作可能违反游戏规则或触发检测，存在账号处罚风险，请自行评估。工具使用普通前台输入和被动网络观测，不读取游戏进程内存、不注入、不发送或重放游戏数据包；这些方式不构成账号安全保证。

当前抓包适配面向港澳台服，韩服、日服尚未验证。一轮停止使用抓包估计起点和乐谱周期，实际游戏停止效果仍需按自己的环境确认；数据不足时请用房主手动全停。输入回执仅代表系统已发送输入，不代表角色已成功执行。同步效果可用本机时间微调调整。

默认诊断不保存原始抓包、完整乐谱或聊天草稿。房间内会共享昵称、分组、角色关联、乐谱摘要和操作状态，请只向可信玩家分享邀请。

赞助完全自愿，不影响工具功能。
