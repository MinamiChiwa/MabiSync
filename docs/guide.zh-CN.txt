MabiSync 使用说明

MabiSync 可以让多人同时触发表情动作，也可以让多个合奏小组同步开始，并由房主统一停止演奏。异地玩家也能使用。

1. 下载与启动

适用于 Windows 10/11 x64。完整解压发布包，双击 MabiSync.exe。

右上角：爱心打开赞助窗口，图钉切换置顶，划线眼睛切换录屏隐藏。置顶默认开启；录屏隐藏默认关闭，手动选择后会记住设置。高亮表示开启，灰色表示关闭。隐藏适用于 Windows 10 2004 及以上的兼容采集软件，部分采集方式仍可能显示窗口。

NVIDIA 录制无法启动时，先关闭“录屏隐藏”再重试。录制时可将工具最小化；最小化不等于从所有录屏方式中排除窗口。

首次启动时填写自己的游戏昵称，设置会自动保存。升级时将新包解压到新文件夹；如果修改过乐器列表，请保留原来的 Config/乐器列表.txt。

左上角显示当前版本，旁边的“检查更新”连接 GitHub 查询正式版。发现新版后，点击“下载更新”才开始下载。下载期间可以继续使用；下次正常打开工具时安装，个人设置和自定义乐器会保留。有适用的增量包时只下载变动文件，否则下载完整更新包。连接 GitHub 失败时可稍后重试。

2. 创建或加入房间

默认“服务器直连（非长期）”：房主填写昵称后点击“创建公网房间”，把邀请或六位房间码发给好友。成员选择相同方式，粘贴邀请或填写房间码，点击“加入房间”。连接使用 WSS 加密；服务为非长期入口，暂停时可改用其他方式。

Cloudflare：房主选择“Cloudflare 公网”，点击“创建公网房间”。显示连接成功后，复制完整邀请发给好友。成员粘贴完整邀请加入。

局域网：双方连接同一路由器，或先用 Tailscale 等组网软件互通。房主选择“局域网”，选择本机地址后创建房间，复制邀请分享。成员粘贴邀请加入，也可填写房主地址和房间码。选择局域网时，旁边的“连接教程”有详细步骤。

进入房间后，由房主选择“表情动作”或“合奏”，安排本轮参与者，设置倒计时。成员准备好后点击“就绪”，房主直接点击“开始”。

房主关闭房间后，所有在线成员退出。重新建房需要分享新邀请。

连接中断时，点击“重新连接”。出现“房间已重新连接”且成员列表恢复后，成员重新就绪。房主也可点击“关闭房间”；服务不可达时会提示关房是否已获确认。

3. 先设置本机游戏操作

每位玩家都在“本机动作”卡片中完成设置：

① 保持“操作游戏”开启，选择自己的游戏窗口。
② 根据需要选择输入方式。

- 预填指令 · 仅按回车：在游戏聊天框提前填好动作指令，由工具在倒计时结束时按回车。
- 快捷键：点击录入框，直接按下游戏中对应的快捷键。
- 游戏按钮：点击“点选按钮位置”，工具隐藏后，再点击游戏中的目标按钮记录位置。

点选位置时，右键、Esc 或本机停止快捷键（默认 F9）可以取消。改变游戏窗口尺寸或 Windows 缩放后，请重新记录按钮位置。

房主点击“开始”后，各参与者的工具会自动恢复并激活自己选择的游戏窗口。执行动作时，请保持游戏在前台，并松开其他按键。

4. 同步表情动作

推荐使用“预填指令 · 仅按回车”：

① 房主选择“表情动作”模式。
② 每人在游戏聊天框填好自己已拥有的动作指令，例如台服 /傳統舞，保留在输入框中。
③ 成员回到工具点击“就绪”；房主准备好后点击“开始”。
④ 工具切回各自的游戏窗口，倒计时结束后统一按一次回车。

下一轮需要重新填好指令、重新就绪。

表情模式只负责触发动作。倒计时结束前可以取消；动作已经播放后，按 F9 不会结束该动作。

5. 同步合奏

一个房间可以安排多个合奏小组。每组由一位乐谱使用者使用自己的乐谱开始演奏，其余组员在游戏中手动加入。

默认进入“合奏”。房主在成员列表中安排分组、顺序、身份和乐器。可以直接编辑，也可以拖动成员调整；全员都会看到最新安排。右键成员可设置总指挥或移出房间。

成员卡片会随人数展开，人数较多时滚动整个页面查看。

开始前需要准备：

- 小组乐谱使用者：在背包选好乐谱，点选乐谱的“使用”按钮位置。停止默认按空格键，也可改为自己的快捷键或停止按钮。
- 小组参与者：确认停止设置（默认空格键），按列表顺序在游戏中手动加入。

参与者也可以提前设置开始按键或按钮，旁边会显示“参与者不触发”。当前身份仍由玩家手动加入；房主将你改为乐谱使用者后，工具才会使用保存的开始设置。

成员就绪后，房主点击“开始”。倒计时结束时，工具统一点击各组乐谱使用者的开始按钮。组员随后靠近本组乐谱使用者，按列表顺序自行加入。

乐器列用于约定分工，请玩家自行在游戏中装备。

启用抓包识别后，列表会显示加入情况：绿色为顺序正确，红色为顺序不符，黄色为待加入，灰蓝色为尚未核对。

6. 选择什么时候结束演奏

房主在底部状态卡选择停止方式：

- 总指挥一轮后全员停止：根据总指挥的乐谱，播放完整一轮后安排所有参与者停止。
- 房主手动统一停止：由房主点击“全员停止”。
- 手动指定演奏时长：按房主填写的时长安排停止。

首次使用默认选择“总指挥一轮后全员停止”。

总指挥的作用是提供全队统一结束的参考乐谱。总指挥可以和房主是不同的人，也可以是手动加入的组员；各组仍由自己的乐谱使用者开始。

使用一轮停止时，总指挥需要先开启抓包识别。工具识别到本轮乐谱后，会在底部显示乐谱信息和停止倒计时。结束时间按完整乐谱计算，较短声部可能提前演奏完。

如果没有出现停止倒计时，请查看底部原因，并由房主手动全停。总指挥提前停止或识别中断时，房主可选择全停；已有停止计划时，也可选择继续到原定终点。

F9 被其他程序占用时，工具依次尝试 Ctrl+Alt+F9、Ctrl+Shift+F9，实际按键显示在“本机动作”中；全部被占用时，使用窗口里的本机停止按钮。

本机停止键只取消或停止本机；房主点击“全员停止”才会通知全队。

7. 开启昵称、乐谱和加入顺序识别

这些功能需要安装 Npcap，官方下载：https://npcap.com/#download 。发布包未附带该驱动。普通表情同步和手动开停可以直接使用。

安装后：

① 点击昵称旁的“抓包校对”。
② 选择自己的游戏和网络通道，点击“开始”。
③ 在游戏中切换地图或重新登录角色。
④ 等工具显示本机角色昵称，确认识别成功。

显示收到流量，但没有识别出昵称时，可以换一个网络通道重试。关闭校对窗口后，识别仍会继续运行。

一轮停止需要总指挥开启识别；加入顺序反馈需要能看到该组成员的玩家开启识别，通常由各组乐谱使用者开启。未开启识别的成员，可由房主右键昵称，通过“匹配游戏角色”选择对应角色。

当前抓包识别适配港澳台服。韩服、日服尚未验证，仍可尝试普通输入同步。

8. 调整同步时间

底部“本机时间微调”只影响自己的动作时间：

- 负数提前：−100 表示提前 100 毫秒。
- 正数延后：+100 表示延后 100 毫秒。
- 0 表示不调整。

支持拖动滑块或输入整数，范围为 −2000～+2000 毫秒。修改后，成员需要重新就绪。

倒计时由房主设置，范围为 1～60 秒。提前量较大或网络准备需要更多时间时，工具会自动延长本轮倒计时，实际时间显示在底部。

9. 遇到问题时

- 公网创建或加入失败：查看底部提示后重试；房主重新建房后，分享新邀请。公网连接受各方网络影响。
- 邀请复制失败：使用按钮下方显示的完整邀请，选中后按 Ctrl+C。
- 找不到游戏窗口：点击“刷新窗口”；仍未出现时，勾选“显示其他窗口”。
- 按钮位置失效：按当前游戏窗口尺寸和 Windows 缩放重新点选。
- 提示输入权限不匹配：让工具与游戏以相同权限运行。
- 昵称或乐谱未识别：检查抓包通道，并切换地图或重新登录角色。
- 仍无法解决：点击“导出诊断”，反馈版本、游戏服务器、操作步骤和底部提示。

“高级连接”保留手动填写服务地址的入口。

卡片可以点击标题收起。当前状态、倒计时和操作结果集中显示在底部。

使用前请了解

MabiSync 不是游戏官方软件。抓包和自动键鼠操作可能违反游戏规则或触发检测，存在账号处罚风险，请自行评估。

一轮停止采用估计的演奏起点，实际效果可能因游戏和网络环境而变化。工具显示输入已执行后，请以游戏内表现为准。邀请仅分享给可信玩家，提交诊断前请检查个人信息。
