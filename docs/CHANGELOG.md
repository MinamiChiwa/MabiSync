# 版本记录

## 0.1.0

首个 Windows x64 发布版。

- 通过公网邀请或局域网连接房间，同步触发表情动作及各组演奏发起者的开始操作。
- 倒计时可设为 1–60 秒，本机微调支持负数提前、正数延后，快捷键可直接按键录入。
- 合奏列表支持房主编辑组号、顺序、身份、乐器，实时同步给全员；本机角色和加入状态用颜色区分。
- 支持昵称与乐谱识别、合奏顺序校对、手动全停、指定时长及按总指挥乐谱一轮停止。
- 乐谱、状态及倒计时进度集中显示在底部；支持点击式按钮校准和游戏窗口恢复激活。
- 房主免点就绪；关房后成员退出，旧邀请失效，公网故障有明确提示。
- 抓包校对提供 Npcap 官方下载入口，身份刷新提示为切换地图或重新登录角色。
- 修复总指挥主动离房后下一轮无法正常开始的问题。

抓包当前适配港澳台服；一轮停止采用估计起点，实际游戏效果需自行确认。公网连接依赖 Cloudflare 可达性。暂未提供浮窗、多语言界面或自动更新。
