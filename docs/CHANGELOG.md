# 版本记录

## 0.1.8

- 一轮自动停止增加“尾音保留”，避免在乐谱时值结束时立即切断最后音符的淡出。默认 1 秒，房主可调整为 0–10 秒，全员共用。
- 尾音保留只延后停止，不改变开始时间、乐谱时长或本机时间微调。本轮开始后设置固定。
- 主窗口和信息浮窗显示尾音保留阶段及停止倒计时，乐谱进度保持在一轮终点。
- 诊断导出增加去除身份信息的乐谱周期与停止计时，便于排查结束时间问题。

局域网和 Cloudflare 建房已附带新版服务。服务器直连需由维护者更新房间服务，旧服务会明确提示暂不支持尾音保留。服务更新方法见 [房间服务更新](server-update.zh-CN.txt)。

不同乐器和乐谱的尾音需要试听调整；保留过长可能听到自动循环的下一轮开头。

## 0.1.7

- 底部乐谱信息旁增加“信息浮窗”，显示成员身份、顺序、乐器、就绪状态、乐谱及进度；房主可开始，成员可就绪。
- 浮窗与主窗口实时联动，支持拖动、关闭和不透明度调整，自动置顶；主窗口默认不置顶。
- 浮窗成员列表可完全收起并自动缩小高度，保留乐谱进度和操作按钮；展开后显示最新成员信息。
- 成功识别角色后的抓包提示显示绿色。
- 修复同一游戏连接内切图或移除本机角色对象后，无法用新角色数据恢复识别的问题。

## 0.1.6

- 发送演奏停止操作前，自动恢复并激活各自选中的游戏窗口；覆盖定时停止、房主统一停止和本机停止。
- 游戏窗口最小化、被其他窗口遮住或失去焦点时，停止操作仍会先恢复窗口再发送按键或点击。
- 激活失败时显示适用于开始和停止的统一提示，不再误导为只能重试开始。

## 0.1.5

- 主界面标题旁显示当前版本号，方便核对正在使用的版本。
- 版本号旁增加“检查更新”。检查 GitHub 正式版后，由玩家选择下载；支持增量包，下载完成后在下次打开工具时安装，保留个人设置和自定义乐器。
- 更新文件会先校验并检查新版能否启动，安装失败时恢复原版。
- 录屏隐藏默认关闭并记住手动选择，避免每次启动自动开启后影响 NVIDIA 录制。
- 录屏隐藏提示增加 NVIDIA 兼容性说明；关闭时会清除主窗口及已打开子窗口的捕获排除标记。

## 0.1.4

- 成员列表随人数展开，使用页面滚动查看，不再限制为固定高度。
- 合奏参与者也可提前设置开始按键或按钮；显示“参与者不触发”，改为乐谱使用者后使用已保存的设置。

升级前退出旧程序，将新包完整解压到新目录。个人设置自动保留；自定义乐器请从旧目录复制 `Config/乐器列表.txt`。

## 0.1.3

- 修复 F9 被其他程序占用时无法就绪或开始的问题。
- F9 不可用时自动尝试 Ctrl+Alt+F9、Ctrl+Shift+F9，界面显示实际可用的本机停止键。全部被占用时仍可使用窗口里的本机停止按钮。
- 简化按键设置、就绪、演奏停止、抓包识别和联机提示，报错时说明需要怎样处理。
- 执行记录使用中文状态，区分操作已发送和游戏中是否生效。
- 修复右上角图标显示不完整的问题，点击和键盘聚焦时也能完整显示。

升级前退出旧程序，将新包完整解压到新目录。个人设置自动保留；自定义乐器请从旧目录复制 `Config/乐器列表.txt`。

## 0.1.2

- 默认通过加密连接使用“服务器直连（非长期）”，保留局域网与 Cloudflare 建房，移除 EasyTier 组件。
- 增加局域网连接教程，连接中断后可重新连接；恢复身份和成员列表后显示成功提示。
- 修复房主断线后无法关闭房间的问题，重连等待期间也可关闭或离开。
- 精简底部状态卡片，折叠后仍可使用开始、就绪及本轮操作按钮。说明集中到功能旁的问号提示。
- 房主显示“等待全员就绪”或“全员已就绪”；成员显示“未就绪”或“已就绪”，就绪按钮分别使用红色与绿色。
- 启动时自动刷新游戏窗口，本机动作标题与窗口状态紧邻显示。顶部身份栏增加乐器信息。
- 合奏身份统一称为“乐谱使用者”，同组可直接更换，修改结果同步到全员。
- 分组颜色仅显示在“组”列，其他列保留统一底色；窗口较窄时可横向滚动成员列表。
- 首次使用默认合奏模式，开始选用游戏按钮，停止选用空格键；已有个人设置继续保留。
- 右上角新增置顶与录屏隐藏开关，默认开启，高亮表示开启，灰色表示关闭。悬停可查看说明。
- 使用新的音符与同步圆环图标，覆盖运行文件、窗口和任务栏。

升级时退出旧程序，将新包完整解压到新目录。个人设置自动保留；自定义乐器请从旧目录复制 `Config/乐器列表.txt`。

录屏隐藏需要 Windows 10 2004 或更高版本及兼容的采集软件。抓包仍仅适配港澳台服，一轮停止使用估计起点与乐谱周期。

## 0.1.1

- 在抓包校对中选择游戏后，自动同步到本机操作窗口。
- 公网连接重试时更新提示，忽略已过期的状态回调，避免旧错误覆盖当前结果。
- 使用说明按玩家操作顺序重新整理。
- 首次启动时昵称框留空，可自行填写或通过抓包识别更新；保留玩家已保存的昵称。
- 改用暗色主题，卡片可收起并保留设置摘要。本机动作集中显示在成员列表前，入房前即可设置。
- 本机时间微调支持 1 毫秒滑块和整数输入，负数提前、正数延后；默认展开，收起后仍显示当前值。
- 修复提前量为负数时合奏开始失败的问题。就绪和开始前自动校时，倒计时会为网络准备和提前量补足时间。
- 房主开始后，各参与者会自动恢复、激活自己选中的游戏窗口；取消和停止在窗口恢复期间仍可使用。
- 最小化后仍能选择游戏窗口、保留抓包观测；窗口列表显示标题、进程与状态，并可展开其他窗口供手动选择。
- 复制邀请后显示成功反馈；剪贴板短暂占用时自动重试，仍被占用时显示完整邀请供手动复制。
- 停止方式集中在底部，初次使用默认总指挥一轮后全员停止。鼠标滚轮不再改动下拉菜单选项。

升级时退出旧程序，将新包完整解压到新目录。个人设置自动保留；自定义乐器请从旧目录复制 `Config/乐器列表.txt`。

抓包仍仅适配港澳台服；选择其他服务器窗口可用于普通输入同步。一轮停止仍采用估计起点，实际游戏效果请按自己的环境确认。

## 0.1.0

首个 Windows x64 发布版。

- 通过公网邀请或局域网连接房间，同步触发表情动作及各组演奏发起者的开始操作。
- 倒计时可设为 1–60 秒，本机微调支持负数提前、正数延后，快捷键可直接按键录入。
- 合奏列表支持房主编辑组号、顺序、身份、乐器，实时同步给全员；本机角色和加入状态用颜色区分。
- 支持昵称与乐谱识别、合奏顺序校对、手动全停、指定时长及按总指挥乐谱一轮停止。
- 乐谱、状态及倒计时进度集中显示在底部；支持点击式按钮校准和游戏窗口恢复激活。
- 房主免点就绪；关房后成员退出，旧邀请失效，公网故障有明确提示。
- 抓包校对提供 Npcap 官方下载入口，身份刷新提示为切换地图或重新登录角色。
- 修复总指挥主动离房后下一轮无法正常开始的问题。

抓包当前适配港澳台服；一轮停止采用估计起点，实际游戏效果需自行确认。公网连接依赖 Cloudflare 可达性。暂未提供浮窗、多语言界面或自动更新。
