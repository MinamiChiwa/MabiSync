MabiSync 0.1.8 房间服务更新

仅使用“服务器直连”的服务器维护者需要操作。局域网和 Cloudflare 建房已由新版工具提供对应服务。

从 0.1.8 发布页下载 MabiSync-Server-Tail-0.1.8.zip，在服务器上解压。补丁包含两个服务文件；原来的 HTTPS 证书、代理和启动配置继续使用。

1. 在服务器的任务计划程序中，找到“MabiSync 房间服务”。在“操作”中查看原来的工作目录。
2. 通知成员退出房间，结束这项任务。将原工作目录中的 server 文件夹复制一份留作备份。
3. 将补丁 server 文件夹里的两个 .js 文件复制到原工作目录的 server 文件夹，替换同名文件。保留原有 index.js。
4. 在任务计划程序中重新运行“MabiSync 房间服务”。
5. 用浏览器打开原来的 HTTPS 地址，并在末尾加 /health。页面应包含 "firstCycleTail":1，表示更新成功。
6. 房主使用 0.1.8 重新建房，在底部设置“尾音保留”。默认 1 秒，试听后调整。

重启会清除原有房间，请分享新房间邀请。
若服务启动失败，先结束任务，恢复备份的两个文件，再重新运行任务。
